# 韩叙 · 个人商业方向 Skill

通过对话，把专业经历、兴趣与人生阶段，变成可以讨论和验证的业务方向及商业模式建议。

适合有经验、想转型、做副业或经营自己业务却方向不清的人；也支持多方向取舍和已有模式调整。你不需要先写定位、目标用户或商业模式，可以从“我现在很迷茫”开始。

## 使用后应能说清什么

- 现阶段适合做什么，为什么与你的经历、偏好和现实条件匹配。
- 先服务谁，解决什么具体问题，对方为什么可能选你。
- 提供什么产品、交付什么、如何形成收费判断。
- 从哪里接触第一批及后续客户，怎样累积信任、让人知道可以买什么。
- 哪项前提不确定，下一步怎样补证。

## 安装和开始

源仓库技能在 `skills/hanxu-business-direction/`。把整个目录复制到 Codex 的 `~/.codex/skills/` 下；安装包解压后也会得到同名目录，可直接复制。不要只复制 `SKILL.md`，它需要 `references/`。

在可加载该技能的新会话中说：

> 用 $hanxu-business-direction，通过提问帮我判断现阶段适合做什么，最后说清服务谁、卖什么产品、怎么获客。

也能直接问“该保留现有业务还是换方向？”“经历能提供什么产品？”，按问题范围推进。

其他支持 `SKILL.md` 与相对引用的助手可按其安装方式使用本目录；本版未验证所有客户端兼容性。

技能本身无代码执行、API密钥或专有服务依赖。需要可读本包的AI助手及其额度；实时市场资料、文件导出等额外能力依使用环境，费用按实际服务。

## 方法与版本

方法来自韩叙的专业细分与要素重组、优势需求愿景约束四视角、自圈层与用户场景、产品作为解决方案、信任与匹配、交付和经营反馈。四项商业判断整合为一个对话入口。

在完整阅读32份授权咨询逐字稿后形成v0.2.0。3组属于同一人的不同轮沟通，约29位已识别对象；不把32份当成32个成功案例。研究覆盖开头、完整问答、用户纠正、闲谈与结尾，未重新复听原始录音。逐案证据留在私有研究区，公开包只放抽象方法和合成演示。

本版增加按真实卡点分流、逐人回忆求助、可撤回的场景假设、反事实提问、纠正后更新整条建议、经营容量和阶段顺序判断。既有业务、长期副业、先转主业与暂不确定方向都有处理方式。末尾以有观察信号和投入边界的小验证收束。

咨询经验中有条件的判断，不能变成“人人卖课、做IP或高客单”的规定。行业事实、用户自述、方法归纳和经营结果分别对待。合成示例和维护者回放不代表独立新用户测试或商业效果。

v0.3.0 使用6个真实案例进行遮蔽原建议的独立上下文、多轮回放，测试端只看技能和用户侧事实。发现“经营目标没有约束主购买场景”和“沿初始人群探索过久”两处不足，据此补充判断。原始对话由维护者代答，不是原用户实时参与；案例已用于此前方法学习，因此属于原建议遮蔽的回归测试，不代表未见样本泛化或市场效果。修订后的复测记录保留在私有研究区。

v0.4.1 继续用此前未参加行为回放的案例检查主动追问：只回答实际问到且原稿有依据的内容，未问事实不提前补入，原稿没有的答案留为未知。修订重点是区分当前尝试与长期方向、主动发现未提到的项目，以及分开核对理想生活与现实时间精力。修订后同时用其他新案例和相同开场的新上下文检查。测试过程、代答校正与局限保留在私有记录；提问行为改善不等于已完整复刻作者判断，独立新用户及经营结果仍待验证。

v0.5.1 回到原稿补充“做过什么→怎样判断→可迁移的粗原则”和“能力组合→买方任务→角色与交付责任变化”。用户讲不出完整故事时，可从日常取舍、小任务或作品比较入手；新工具诉求仍需与已有任务比较需求、能力、投入及意愿。另明确未来想接近家人不等于已承担照护。新增案例继续按实际问题释放事实，事实校对端通读原稿，建议端只看冻结技能、简短开场和逐轮回答。候选版与修订版分别记录，不把不同版本混称同一次验证。本轮也更正前轮代答遗漏已有信息造成的归因；旧记录保留，不能把全部不足都算作技能问题。

v0.5.2 补充从实际解释、材料组织和客户理解中追问内容能力。客户不看方案时，区分表达、问题优先级、信任、决策权与投入，避免只追分析指标或先断定客户不懂。新增回放与前版分别留档，不把写入规则当行为已通过。

v0.6.1 继续完整回读原咨询，把“本人优势、客户任务、产品、信任证据与实际入口”接到同一段经历中。独特性不要求新形式；可用原有产品，也可重组角色和责任，不能为新而造需求。区分公司引入、本人维持与陌生人重新选择的信任；渠道按实际接触及合作边界判断，小验证说明与长期产品的关系。新增回放中发现局部销售材料可能吞掉品牌目标，据此增加目标校准和本人判断追问，再用另一类未测试案例继续检查。冻结版本、逐问代答校正和未学会部分保留私有记录；不将不同版本混称终版验证。

v0.6.2 继续区分作品/流程证据与对本人的托付，追真实评价、取舍及合作行为；核清样品、商品和未注明归属的订单，不把一项成交借给整个新模式。再以已有付费业务的不同案例逐问回放，结论仍限于观察到的行为和明确的未知。

v0.7.0 从真实认识、被托付的任务、长期看过的工作与后续行为，帮助提炼可校正的个人优势解释，再约束产品责任；判断支持不自动扩大成执行或结果保证。区分有限老关系中的持续可见与同类新人的来源，长期入口需说明实际场景、可被理解的判断和产品承接。修订后冻结同一版，再用不同未测试案例逐问回放；原建议、代答范围、未知与未学会部分留在私有比较中，不以同版测试代替新用户和经营结果验证。

v0.8.0 继续回原稿补专业经验如何改变客户决定、谁能执行，以及伙伴作为购买方、介绍方和共同交付方的不同责任；持续获客结合认知解释、真实判断、合作入口与内容成本，不能只剩一次观察。修后先冻结同一版，再用此前未行为回放的不同案例逐问检查；完整结果与原判断比较保留私有区，未知和不足照实呈现。

v0.8.1 进一步区分是否立即投入与已有条件能怎样组成业务。用合作方实际接触的人、服务触点与互补利益解释渠道和共同交付，不因报酬或时间未知就只剩核实；同时把有用的专业判断、本人取舍和可购买任务连到持续信任。修后再冻结同一版回放其他未测逐字稿；其中有同一人的另一轮沟通，不作为新用户验证。

v0.9.0 从非正式帮忙、自主兴趣投入和他人愿帮助的具体关系中，追本人动作、他人反应及跨阶段重复做法；帮助动机未知时保留未知，不以自我否定抹去能力。再把优势接到具体买方任务与有限产品，从实际认识过程反推可重复的接触、信任和购买入口。修后冻结回放最后一份此前未行为测试的逐字稿；它属于已出现过的人的另一轮谈话，整个语料池已参与方法学习，不作为独立新用户验证。

v0.10.0 把具体判断继续提炼成取舍原则、适用任务与客户可能得到的变化，再推可负责的产品和收费逻辑；小试验验证其中一环，不替代整套模式。已有初想时比较真实相邻机会；从反复求助及交付条件倒推持续入口和伙伴分工。全部32份此前已参加回放，本轮选不同旧案例按同一冻结版回归、逐问放行事实并事后比较原判断，明确不是新盲测；不足不以规则写入或结构检查冒充通过。

v0.11.0 重写“为什么偏偏选本人”的关系追问与推断、经验转为有期限学习实践产品的形成过程，以及从交付必经步骤推到伙伴销售与共同交付的方法；合并重复自查，避免只加清单。维护回归使用与上一轮不同的旧案例，冻结同版、按实际问题释放事实、结束后比较原判断；不是新盲测，也不以规则修改或打包检查宣称方法已掌握。

方向与模式是有依据、仍可修正的建议。技能不承诺收入，不替你决定辞职投入，不自动投简历、联系客户、报价或发布。
