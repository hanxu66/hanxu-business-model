# 韩叙个人商业模式skill

Hanxu Personal Business Model Skill.

通过逐步对话，把你的专业经验、兴趣和现实条件，整理成可以讨论和验证的个人商业方案。

这是一套可以安装到AI助手里的技能包，基于韩叙的个人商业模式方法和咨询对话研究整理。安装后，AI会从你的具体经历入手，逐步提问、给出判断，再根据你的补充和纠正调整建议。你可以从一句“我现在不知道能做什么”开始。

如果你正处在这些情况，它可以帮你梳理：

- 有工作经验，正在考虑转型或发展副业，但不知道什么适合自己。
- 想做自由职业、咨询或其他个人业务，却说不清自己的优势和能卖什么。
- 对几个方向都有兴趣，希望结合收入、时间、家庭和人生阶段作取舍。
- 已经有客户或业务，需要调整产品、合作方式或获客路径。

在对话中，它会帮助你逐步厘清五件事：

1. 你现在更适合做什么。结合经历、具体判断、兴趣和现实约束，提炼有依据的优势，比较方向及进入顺序。
2. 先服务谁。找到更具体的人群、问题和使用场景，分析对方可能为什么选择你。
3. 先卖什么。一版可修改的产品方案，包括客户买到什么、主要交付、粗略周期、双方责任和收费逻辑。
4. 怎样合作与获客。需要伙伴时说明分工和收益依据，并把客户来源、信任证据与购买入口接起来。
5. 下一步验证什么。说明关键假设、可以先做的小尝试、观察什么，以及什么情况需要调整。

最终，你应当能更清楚地说出：

“我现阶段适合以什么角色，为哪类人解决什么问题，提供什么产品，怎样收费和交付，客户从哪里来，以及下一步先验证什么。”

你也可以只讨论当前一个问题，例如“我的经验能变成什么产品”“这两个方向怎么选”“合作伙伴该怎样分工”。

## 安装与开始使用

以下以可以访问本地文件、支持Skill的Codex为例。先准备好可正常使用的Codex账号。本技能可从GitHub免费下载，AI工具的账号、订阅或调用额度由你自行准备。

中文展示名为“韩叙个人商业模式skill”；英文名称为 Hanxu Personal Business Model Skill；内部标识和文件夹名为 `hanxu-business-model`，显式调用写作 `$hanxu-business-model`。

### 1. 安装技能

**从GitHub安装：**在Codex的新对话中，复制并发送下面的指令。

```text
请使用 $skill-installer，从 GitHub 仓库 https://github.com/hanxu66/hanxu-business-model 安装 skills/hanxu-business-model 目录中的技能。请完整保留它的引用文件，安装后检查是否可以识别 hanxu-business-model，并告诉我实际安装位置和版本。
```

**从ZIP安装：**到[当前公开发布版](https://github.com/hanxu66/hanxu-business-model/releases/latest)下载 `hanxu-business-model-v<版本号>.zip`，解压后保留完整的 `hanxu-business-model` 文件夹，再把实际路径告诉Codex，请它帮助安装到个人技能目录。已经拿到本安装包的用户可直接解压，无需再次下载。

```text
请把我提供的解压目录中的 hanxu-business-model 安装到当前Codex的个人技能目录。完整保留 SKILL.md、references、agents、README.md 和 LICENSE，告诉我实际安装位置和版本。如果有同名或旧名技能，先检查冲突，备份到技能扫描目录以外，再替换，不删除维护源码。
```

不要只复制 `SKILL.md`。技能不依赖其他Skill、私有知识库、API密钥或代码执行；`$skill-installer`只用于上述GitHub安装方式，使用本技能时不需要它。其他支持SKILL.md的客户端可按其方式安装，未逐客户端验证兼容性。

从旧版升级时，需同时检查 `hanxu-business-direction` 和 `hanxu-business-model`，避免两个版本重复加载。

### 2. 打开新对话

安装后新建一次对话。如果尚未识别到技能，重启Codex再试。Codex的个人技能目录由当前版本和安装工具确定，请以实际安装结果为准；当前官方文档列出 `~/.agents/skills/`，本技能维护环境也使用 `~/.codex/skills/`。不需要向两个位置重复安装。

### 3. 开始第一次对话

复制下面这段话，再按实际情况回答：

```text
用 $hanxu-business-model 帮我梳理个人商业模式。我有一些专业经验，但还没想清楚现在适合做什么。请先了解我的情况，每次问少量相关问题，边了解边给判断。最后帮我形成一版方向、目标用户、产品与收费、合作及获客建议，并说明下一步先验证什么。
```

尽量讲具体事情：做过什么、别人为什么找你、你作过什么判断、喜欢和不愿长期承担什么。没有想清楚的可以直接说不知道；建议不符合你的情况，就指出哪一点不对，让它继续调整。你不需要先把自己的定位和商业模式写好。

本技能聚焦个人业务与商业模式建议，岗位匹配和简历投递不在其范围内。建议由你使用的AI工具按技能方法生成，收入、成交和经营效果需要现实验证。请按自己的条件决定是否辞职、投入或对外承诺。

源码与更新：[hanxu66/hanxu-business-model](https://github.com/hanxu66/hanxu-business-model)。Codex安装机制参考：[OpenAI官方文档](https://learn.chatgpt.com/docs/build-skills#install-curated-skills-for-local-use)。

## 方法与验证范围

方法来自韩叙的专业细分、要素重组、优势需求愿景约束四视角、自圈层、产品解决方案、信任与持续经营方法。已对32份授权咨询逐字稿进行全文方法研究，其中包括同一人的续谈，约29位已识别对象；这些不是32个成功商业案例。

维护采用冻结版本、独立建议上下文、按实际问题释放原稿本人事实、结束后比较原判断的旧案例回归。原稿没有的新选择和反馈不模拟。全部旧材料已参与学习，回归结果不能当未见用户测试、版本因果或经营效果证明。具体发布版本的检查范围和已知限制保存在GitHub Release说明。

v0.14.0从买方结果推首期产品，按实际贡献设计合作与持续入口；明确未确认与拒绝的区别，让方案保留条件而不退回候选，并以合成示例展示完整交易。v0.15.0统一中文名称、英文标识、仓库和目录命名，解题方法沿用v0.14.0。v0.15.1候选版同步用户介绍、安装和首次对话说明，方法内容未变；在韩叙亲测前不发布本次更新。技能提供建议，不承诺收入或教学、获客效果，不替用户决定辞职、投入或正式对外承诺。
