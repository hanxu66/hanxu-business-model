# 韩叙 · 个人商业方向 Skill

通过对话，把专业经历、兴趣与人生阶段，变成可以讨论和验证的业务方向及商业模式建议。

适合有经验、想转型、做副业或经营自己业务却方向不清的人；也支持多方向取舍和已有模式调整。你不需要先写定位、目标用户或商业模式，可以从“我现在很迷茫”开始。

## 使用后应能说清什么

- 现阶段适合做什么，为什么与你的经历、偏好和现实条件匹配。
- 先服务谁，解决什么具体问题，对方为什么可能选你。
- 提供什么产品、交付什么、如何形成收费判断。
- 从哪里接触第一批客户，需要什么信任证据。
- 哪项前提不确定，下一步怎样补证。

## 安装和开始

源仓库技能在 `skills/hanxu-business-direction/`。把整个目录复制到 Codex 的 `~/.codex/skills/` 下；安装包解压后也会得到同名目录，可直接复制。不要只复制 `SKILL.md`，它需要 `references/`。

在可加载该技能的新会话中说：

> 用 $hanxu-business-direction，通过提问帮我判断现阶段适合做什么，最后说清服务谁、卖什么产品、怎么获客。

也能直接问“该保留现有业务还是换方向？”“经历能提供什么产品？”，按问题范围推进。

其他支持 `SKILL.md` 与相对引用的助手可按其安装方式使用本目录；本版未验证所有客户端兼容性。

技能本身无代码执行、API密钥或专有服务依赖。需要可读本包的AI助手及其额度；实时市场资料、文件导出等额外能力依使用环境，费用按实际服务。

## 方法与版本

方法来自韩叙的专业细分与要素重组、优势需求愿景约束四视角、自圈层与用户场景、产品作为解决方案、信任与匹配、交付和经营反馈。四项商业判断整合为一个对话入口。

v0.1.0 结合授权咨询语料的关键上下文与现有方法，改进追问、假设讨论和反馈修正。学习范围是候选资料盘点与关键上下文阅读，未逐字穷尽编码全部历史资料。合成示例和维护者回放不代表新用户独立测试或商业效果。

方向与模式是有依据、仍可修正的建议。技能不承诺收入，不替你决定辞职投入，不自动投简历、联系客户、报价或发布。

## 隐私与许可
